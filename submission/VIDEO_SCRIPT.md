# PathLight demo video script (2:50 target, 3:00 maximum)

**Setup before recording**
- Open the live site (or `npm run build && npm run preview`) in Chrome at about 1440 × 900, light mode, zoom 100%.
- Have a phone photo of a printed synthetic report ready (print `#example=melanoma-excision` and photograph it), or use the bundled examples.
- Close other tabs and silence notifications. Record your voice slowly and calmly. Export 1080p MP4. OBS, Loom or Win + Alt + R all work.
